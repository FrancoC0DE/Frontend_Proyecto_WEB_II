Boricuas — Facturación Electrónica

Registrá tu sitio, mandanos tus ventas ya firmadas, y nosotros nos encargamos de validarlas y enviarlas a Mini Tributación (DGTD).

Antes de registrarte, adaptá los OTROS servicios primero

Registrarte acá NO alcanza para poder facturar de verdad. Este servicio solo empaqueta, valida y reenvía a Mini Tributación lo que vos ya tenés armado — necesitás tener resuelto vos mismo, con TU PROPIA identidad, antes de mandarnos tu primera venta:

  • Firma Digital (HSM Sign CR) — registrá tu propio negocio ahí y conseguí tu certificado. Nosotros nunca firmamos por vos: tu PIN nunca sale de tu navegador.
  • Cobro al cliente — tu propia pasarela de pago (ej. BankyFinanzas) para cobrarle a tu cliente antes de facturar. Nosotros no procesamos ningún cobro.
  • Comprobante en PDF (opcional) — si querés un PDF bonito para tu cliente, necesitás tu propia cuenta de Billing Kilometer. La nuestra solo emite a nuestro propio nombre.

Si todavía no tenés esas tres cosas resueltas, andá a hacerlo primero — después volvé acá y registrá tu sitio.

1. Registrá tu sitio

Recibís una API key al instante — se muestra una sola vez, guardala apenas la veas.

2. Cómo integrar (resumen)

Firmar es siempre interactivo — tu PIN de HSM Sign CR nunca sale de tu propio navegador ni pasa por nuestro backend.

  1. POST /sitios (arriba) — una sola vez, obtenés tu API key.
  2. POST /ventas — le mandás los datos de una venta; te devolvemos el XML sin firmar, armado con tu identidad como emisor.
  3. Firmás ese XML con tu propia identificación + PIN en HSM Sign CR (en tu propio sitio).
  4. POST /ventas/:id/firmar — nos mandás el resultado de esa firma; validamos y enviamos a Mini Tributación a nombre tuyo.
  5. GET /ventas/:id — consultás el estado (aceptada/rechazada + número de acuse) cuando quieras.

URL base

https://backend-proyecto-web-ii.onrender.com/api/facturacion

Ejemplo: registrar una venta

curl -X POST https://backend-proyecto-web-ii.onrender.com/api/facturacion/ventas \
  -H "Content-Type: application/json" \
  -H "x-api-key: TU_API_KEY" \
  -d '{
    "referenciaExterna": "ORD-001",
    "clienteNombre": "Ana Pérez",
    "clienteIdentificacion": "1-2345-6789",
    "clienteCorreo": "ana@correo.com",
    "detalle": "Compra en línea",
    "monto": 15000
  }'

Errores comunes

CódigoCausa
401Falta x-api-key, o es inválida / el sitio está inactivo
400Datos inválidos, o la firma/XML no pasó validación
404La factura no existe o no pertenece a tu API key
409Ya intentaste firmar una factura que no está pendiente

Qué NO hacemos por vos

No generamos el comprobante en PDF a tu nombre (necesitás tu propia cuenta de Billing Kilometer para eso), no procesamos el cobro (necesitás tu propia pasarela, ej. BankyFinanzas), y no firmamos por vos — el PIN es tuyo.
